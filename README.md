# English Time

Sitio de [English Time](https://englishtime.com.co): clases de inglés personalizadas 1 a 1 por Zoom.

| Carpeta | Qué hay |
|---|---|
| `web/` | La landing en Next.js 16, exportada como sitio estático. Es lo que se publica. |
| `publicidades/` | Las 5 publicidades en PNG (1080×1350) para WhatsApp e Instagram. |
| `landing/` | La primera versión en HTML, como respaldo. |

Cada cambio que llega a `main` se compila y se publica solo en GitHub Pages (`.github/workflows/publicar.yml`). Las instrucciones para editar textos y precios están en [`web/README.md`](web/README.md).
